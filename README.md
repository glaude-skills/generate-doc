# generate-doc

문서를 쓸 때 AI 특유의 문체를 빼는 Claude Code 스킬.

"AI가 쓴 것처럼 잘 정리된 글"이 아니라 사람이 실제로 쓴 것처럼 쓰게 한다. 정확성과 명확성은 그대로 두고, 상투어와 억지 구조만 걷어낸다.

특정 문서 종류를 위한 게 아니라 글 쓰는 모든 상황에 적용되는 문체 가이드다.

## 설치

새 Claude Code 세션에서:

```
/plugin marketplace add glaude-skills/generate-doc
/plugin install generate-doc@generate-doc
```

## 언제 걸리나

README, 기술 문서, 이메일, 보고서, 블로그, 릴리스 노트, 커밋/PR 설명처럼 사람이 읽을 글을 쓰거나 고칠 때. "AI 티 빼줘", "사람이 쓴 것처럼" 같은 요청에도 걸린다. 문서뿐 아니라 일반 대화 답변에도 적용된다.

## 뭘 막나

- 접속 상투어: "이를 통해", "종합하면", "궁극적으로", "결론적으로", "다시 말해"
- 과잉 친절 리액션: "좋은 질문입니다", "물론입니다", "핵심을 잘 짚으셨습니다"
- 습관적 마무리 교훈: "결국 중요한 것은 ~입니다"
- 문서용 공허한 동사구: "~을 수행하였습니다", "~에 기여하였습니다", "~의 기반을 마련하였습니다"
- 추상어: 구체적으로 쓸 수 있으면 구체적으로
- 억지 균형, 억지 목록, 같은 내용 두 번 요약
- 주어지지 않은 사실을 지어내는 것
- 꾸밈말 반복: "성공적으로", "안정적으로", "다양한", "의미 있는", "결과적으로"
- 같은 어미가 줄줄이 이어지는 문장, 한국어로 써도 되는 자리의 영어 용어
- "주요 성과", "향후 계획"처럼 아무 문서에나 붙는 제목
- 근거가 약한데 단정하는 것, 확인된 사실을 흐리는 것

보고서, 기술 문서, 회의록, 자기소개서는 종류마다 따로 챙길 점이 SKILL.md에 있다. 예를 들어 회의록은 정해진 것과 논의만 된 것을 나눠 적는다.

## 구조

```
skills/generate-doc/SKILL.md   스킬 본문
.claude-plugin/                플러그인 매니페스트
.ai/                           프로젝트 정책
```
