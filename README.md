# generate-doc

문서와 답변에서 AI 특유의 문체를 빼는 Claude Code 스킬.

"AI가 쓴 것처럼 잘 정리된 글"이 아니라 사람이 실제로 쓴 것처럼 쓰게 한다. 정확성과 명확성은 그대로 두고, 상투어와 억지 구조만 걷어낸다.

## 설치

새 Claude Code 세션에서:

```
/plugin marketplace add glaude-skills/generate-doc
/plugin install generate-doc@generate-doc
```

## 언제 걸리나

README, 기술 문서, 이력서, 자기소개서, 이메일, 보고서, 블로그, 릴리스 노트, 커밋/PR 설명을 쓰거나 고칠 때. "AI 티 빼줘", "사람이 쓴 것처럼" 같은 요청에도 걸린다. 문서뿐 아니라 일반 대화 답변에도 적용된다.

## 뭘 막나

- 접속 상투어 — "이를 통해", "종합하면", "궁극적으로", "결론적으로", "다시 말해"
- 과잉 친절 리액션 — "좋은 질문입니다", "물론입니다", "핵심을 잘 짚으셨습니다"
- 습관적 마무리 교훈 — "결국 중요한 것은 ~입니다"
- 문서용 공허한 동사구 — "~을 수행하였습니다", "~에 기여하였습니다", "~의 기반을 마련하였습니다"
- 추상어 — 구체적으로 쓸 수 있으면 구체적으로
- 억지 균형, 억지 목록, 같은 내용 두 번 요약
- 주어지지 않은 수치·역할·경험을 지어내는 것

## 실제 차이

같은 재료(관리자 페이지 리팩토링 / 로딩 4.1초 → 1.2초 / Redis 캐싱 / 프론트 2명 백엔드 1명)로 이력서 '주요 성과'를 쓰게 했을 때.

스킬 없이:

```
- 사내 관리자 페이지 리팩토링을 주도하여 목록 페이지 로딩 시간을 4.1초에서 1.2초로 약 71% 단축시킴
- 조회 API에 Redis 캐싱을 도입하여 반복 조회 시 응답 속도와 서버 부하를 크게 개선함
- 프론트엔드 2명, 백엔드 1명으로 구성된 팀에서 성능 개선 작업을 이끌며 협업을 통해 목표를 달성함
```

"주도하여", "이끌며"는 주어진 적 없는 역할이다. "크게 개선", "협업을 통해 목표를 달성"에는 내용이 없다.

스킬 적용:

```
- 관리자 페이지 리팩토링으로 목록 로딩 시간 4.1초에서 1.2초로 단축
- 조회 API에 Redis 캐시 적용
- 프론트엔드 2명, 백엔드 1명 팀에서 성능 개선 작업 담당
```
